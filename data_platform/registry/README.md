# Dataset Registry & Metadata Catalog
**Owner: Sireesha (with contributions from all domain owners)**

## Purpose
Manages dataset cards, download/import scripts, annotation schemas, and indexing references to raw sensor data stored in external file/object storage.

## Ingested Datasets
- **Tier A (Indian Core):** IDD, IDD-3D, Roadscapes, IDS-JODHA, DriveIndia, IndiaScene365, Kerala LiDAR.
- **Tier B (Global Transfer):** nuScenes, Waymo Open Dataset, Argoverse 2.
- **Tier C (Synthetic):** RoadRunner and CARLA scenario variations.
